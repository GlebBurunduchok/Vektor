# Vektor website

Готовий статичний сайт українською та англійською для GitHub Pages.
Без npm, збірки, бази даних або власного сервера. APK уже включено.

## Що в архіві

- index.html — сторінка.
- styles.css — оформлення та адаптація для телефона.
- app.js — мови та перемикання скриншотів.
- config.js — посилання на APK, номер версії та розмір.
- assets/ — власна іконка та справжні скриншоти Vektor у WebP.
- downloads/vektor.apk — APK з твого Android Studio проєкту, пакет com.nogps.navigator, версія 1.0.
- .nojekyll — вимикає обробку Jekyll.
- APK-SHA256.txt — контрольна сума включеного APK.

## Подивитись на комп’ютері

Відкрий index.html у браузері. Для повної перевірки скачування краще опублікувати сайт через GitHub Pages.

## ВАРІАНТ А — завантажити все через GitHub Desktop

APK має приблизно 56 МБ. Через звичайний Upload files у браузері GitHub файли понад 25 MiB не завантажуються.
У цьому варіанті нічого у файлах сайту редагувати не треба.

1. У GitHub створи новий PUBLIC репозиторій, наприклад vektor-app. Додай README при створенні.
2. У GitHub Desktop відкрий File → Clone repository і склонуй цей репозиторій.
3. Відкрий локальну папку репозиторію. Скопіюй у неї ВМІСТ розпакованого архіву: index.html має лежати просто в корені, а не всередині ще однієї папки.
4. У GitHub Desktop напиши короткий опис, наприклад Add Vektor website, натисни Commit to main → Push origin.
5. На GitHub відкрий репозиторій → Settings → Pages.
6. У Build and deployment обери Source: Deploy from a branch. Branch: main, папка /(root). Натисни Save.
7. Дочекайся публікації та відкрий посилання, яке покаже GitHub у Pages.
8. Перевір кнопку Android. Вона завантажує downloads/vektor.apk. iPhone показує «Скоро».

## ВАРІАНТ Б — тільки через браузер, APK у GitHub Releases

Це зручніше для частих оновлень APK: бінарні файли не накопичуються в історії Git.

1. Створи PUBLIC репозиторій vektor-app.
2. Завантаж через Add file → Upload files усі файли сайту, ОКРІМ папки downloads. Перетягування папки assets зберігає структуру. index.html має бути в корені.
3. У репозиторії відкрий Releases → Create a new release / Draft a new release.
4. Створи тег v1.0.0, назви реліз Vektor 1.0 test.
5. Додай downloads/vektor.apk з архіву як файл релізу. Це не звичайний Upload files у репозиторій.
6. Опублікуй реліз і скопіюй ПОСИЛАННЯ САМЕ НА vektor.apk у списку Assets (ім’я файла — vektor.apk, латиницею).
7. Відредагуй config.js: заміни apkUrl на скопійоване повне https-посилання.
8. Також у index.html заміни всі downloads/vektor.apk на це посилання. Це запасні посилання для випадку, коли JavaScript вимкнено.
9. У Settings → Pages увімкни main / (root), як у варіанті А.

## Наступне оновлення

Для варіанта А: заміни downloads/vektor.apk, у config.js онови version та apkSize; за бажання онови контрольну суму. Зроби Commit і Push.
Для варіанта Б: створи новий реліз з APK і онови apkUrl, version, apkSize у config.js, а також запасні посилання у index.html.
Не змінюй підпис APK, якщо користувачі мають установлювати оновлення поверх попередньої версії.
Наразі включено DEBUG-збірку для тестування. Для широкого публічного випуску надалі підготуй підписану release-збірку зі збереженим ключем; сайт працюватиме так само.

## Зміст і поточні можливості

Сайт описує теперішню версію: маршрути, автоперебудування, пошук, збережені місця, дві теми, локальні помітки й навігаційне сповіщення.
Без GPS, повний офлайн, голосові підказки та спільні помітки не рекламуються як готові можливості.
Дата випуску iPhone не обіцяється. Контакти, відгуки й статистику користувачів не вигадано.
Екрани показані українською; при EN перемикається текст сайту, самі скриншоти залишаються справжніми українськими екранами.
Аналітики й зовнішніх шрифтів немає. Мова зберігається локально у браузері.
Публікацію та створення репозиторію цей пакет самостійно не виконує.
